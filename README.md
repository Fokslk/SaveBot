# Save Mod — Telegram Business Bot

Бизнес-бот для Telegram, предназначенный для **логирования личных переписок** и **сохранения медиафайлов**. Бот интегрируется в профиль через раздел **«Автоматизация действий» / «Чат-боты»** в настройках Telegram Business и перехватывает события в личных диалогах.

## Назначение и принцип работы

Save Mod — это сервисный бот для аккаунтов с подпиской **Telegram Business**. После подключения он получает копии всех сообщений из личных чатов, которые ведёт владелец аккаунта, и сохраняет их локально.

### Ключевые функции

| Функция | Описание |
|---------|----------|
| **Удалённые сообщения** | При удалении сообщения собеседником бот находит сохранённую копию текста/медиа и отправляет уведомление в сервисный чат |
| **История редактирования** | При первом редактировании фиксируется оригинальный текст; в сервисный чат приходит diff «было → стало» |
| **Сгорающие и защищённые медиа** | Фото, голосовые, видео-заметки и другие медиа с однократным просмотром сохраняются сразу при получении и остаются доступными после удаления |

> **Важно:** Telegram не позволяет боту пересылать сообщения из бизнес-чатов напрямую. Бот восстанавливает содержимое из своей базы и отправляет копию в сервисный чат.

## Подключение и интеграция

### 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`, задайте имя и username
3. Скопируйте полученный **токен**

### 2. Включите режим секретаря в BotFather

> **Обязательный шаг.** Без него Telegram покажет: *«Этот бот пока не поддерживает режим секретаря»*.

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/mybots` → выберите **@SaveBotSMS_bot** (ваш бот)
3. **Bot Settings** → **Business Mode** (или **Secretary Mode** / **Режим секретаря**)
4. Нажмите **Turn on** / **Включить**

### 3. Запустите Save Mod локально

```powershell
cd "E:\save mod"
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# Отредактируйте .env — вставьте BOT_TOKEN
python -m bot.main
```

### 4. Подключите бота через Telegram Business

1. **Скопируйте `@username` бота** — отправьте боту `/start`, username указан в профиле бота
2. Откройте **Настройки Telegram** → **Telegram для бизнеса** → **Чат-боты** (или **Автоматизация действий**)
3. **Вставьте username бота** и выдайте необходимые права:
   - ✅ **Чтение сообщений** — обязательно (без этого бот не получит события)
   - ✅ **Обработка входящих/исходящих** — для полного логирования переписки
4. Подтвердите подключение — бот пришлёт сообщение «Бизнес-подключение активировано»

### 5. Сервисный чат для уведомлений

По умолчанию уведомления приходят в **личный чат с ботом** (тот же, куда приходит подтверждение подключения).

Чтобы отправлять уведомления в группу или канал, укажите в `.env`:

```env
SERVICE_CHAT_ID=your_service_chat_id
```

> Бота нужно добавить в группу/канал и дать права на отправку сообщений.

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Инструкция по подключению |
| `/status` | Активные подключения и пригласившие их пользователи (после настройки администратора, только в личном чате) |
| `/referal` | Персональная пригласительная ссылка и прогресс до подарка |

### Настройка администратора

Перед использованием `/status` укажите свой Telegram user ID в `ADMIN_USER_ID` в `bot/config.py`. Сейчас поле намеренно оставлено пустым (`None`), поэтому команда покажет напоминание о настройке. Приглашение засчитывается один раз после подключения Telegram Business; за каждые пять подключённых приглашённых можно забрать приз. Если до получения приза накопилось больше пяти приглашений, остаток сохраняется.

## Ограничения Telegram API

- Бот **не может пересылать** сообщения из бизнес-чатов — только воспроизводить сохранённые копии
- Сообщения, отправленные **до подключения** бота, не будут в базе — при их удалении придёт только ID
- Для работы нужна активная подписка **Telegram Business** у владельца аккаунта
- Бот должен быть **запущен постоянно** (VPS, домашний ПК, Docker) для непрерывного логирования

## Запуск в фоне (Windows)

```powershell
# Через pythonw (без окна консоли)
pythonw -m bot.main
```

Для production рекомендуется VPS с systemd или Docker.

## Лицензия

Проект создан для личного использования. Соблюдайте законодательство и политику Telegram при работе с переписками.
